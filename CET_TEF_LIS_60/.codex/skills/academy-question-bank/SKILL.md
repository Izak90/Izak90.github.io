# Workflow
Read docs/CONTENT_RULES.md, docs/QUESTION_BANKS.md and docs/RELEASE_CHECKLIST.md.
Build/verify a source coverage matrix. Preserve IDs when repairing an existing bank when practical. Randomize stored options and recalculate answer. Do not force A/B/C/D balance. Build two disjoint 40Q exams, both covering all major themes. Validate programmatically. For hard items, check the strongest distractor and ensure one best answer.

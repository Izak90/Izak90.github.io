# Content rules

Source priority:
1. trainer/Fitness Academy materials
2. official CET TEEF reference
3. recognised scientific guidelines/literature
4. reference textbooks
5. other sources when necessary

When source files are provided, preserve their terminology, scope and numerical values. If external verification is requested, clearly separate it.

Language: Portuguese (Portugal).

Teaching structure when possible:
o que é → como funciona → porque acontece → como identificar → como aplicar

Tie theory to gym/PT practice and TEF decision-making.

Respect scope: TEF does not diagnose, prescribe medication, perform physiotherapy or psychotherapy.

Assessment summaries should surface:
definitions, mechanisms, comparisons, numerical thresholds, common confusions, practical examples, exam traps, professional relevance.

For assessment-critical UCs, map every Lista de Saberes bullet explicitly. "Covered by theme" is not enough.

Difficulty:
- Fácil: direct recall/recognition.
- Médio: similar definitions, close numbers, interpretation, plausible distractors.
- Difícil: single-best-answer; partly true distractors; cases; I/II/III; MAIS/MENOS correta; threshold edge cases; strong distractors wrong for a precise reason.

Never make a question genuinely ambiguous just to make it difficult.
